# LinkedList Polynomials
![](https://img.shields.io/badge/-Java-informational?style=for-the-badge&logo=Java&logoColor=white&color=007396) 
<img src="https://github.com/Unixado/LinkedList-Polynomials/blob/master/assets/Polynomialdeg3.svg" align="right" width="150">





Implemented in Java and using a singly linked list, this code allows users to define polynomials and run a set of operations on them.
This implementation focuses solely on the time complexity of the algorithms and uses [Horner's](https://en.wikipedia.org/wiki/Horner%27s_method) method for polynomial evaluation.
